What happens when I click Connect?

Blogger opens Google's real authorize page (accounts.google.com/o/oauth2/v2/auth) with the Blogger scope, through the BlogNeo API server. Pinterest opens the real Pinterest authorize page (pinterest.com/oauth). If the owner has not set up the Google / Pinterest app on the server yet, BlogNeo will say so plainly instead of pretending to connect. After you approve on Google / Pinterest, you return to BlogNeo and the connection is verified by the server.
